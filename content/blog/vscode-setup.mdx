# My VS Code Setup

Productivity starts with a comfortable environment. Here is what I use daily.

## Theme & Font

- **Theme**: One Dark Pro or Vesper
- **Font**: Recursive (Monospace Casual)

## Extensions

1.  **Tailwind CSS IntelliSense**: A must-have for utility classes.
2.  **ESLint / Prettier**: Formatting on save.
3.  **GitLens**: Supercharge git blame.

## Keybindings

I map `Caps Lock` to `Escape`. This saves my pinky finger when using Vim keybindings!
