# Hello World

Welcome to my new blog! This platform is built with **Next.js**, **Tailwind CSS**, and **MDX**.

## Why MDX?

MDX allows me to write Markdown while embedding React components. This gives me the speed of writing in Markdown with the flexibility of React.

```tsx
// Example Code Block
function Hello() {
  return <div>Hello World</div>
}
```

## Features

- **Zero Cost**: Hosted on Vercel/Cloudflare.
- **Fast**: Static Generation for reading speed.
- **Themable**: Works perfectly with Dark/Light mode.
